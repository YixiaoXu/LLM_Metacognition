# Quantitative figures

Run `Rscript figures/requirements.R` once, then `Rscript figures/draw_figures.R /path/to/research_data`. Pass a second argument 2, 3, 4, 5 or 6 to render one figure. Outputs go to outputs/figures (or METACOG_FIGURE_OUTPUT). Input data are never modified. Arial must be installed or substituted explicitly on your system.

These plots preserve the observed values and the manuscript panel layout. The native editable Fig. 6 case panel is not reproduced by the R text preview; full case texts are available in source_data/response_examples.json. Fig. 1 illustration assets and historic simulated layout previews are not part of this repository.
